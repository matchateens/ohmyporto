# OhMyPorto — Personal Portfolio

Personal portfolio website for showcasing projects, skills, certificates, education, and work experience.

🔗 **Live**: [atins.my.id](https://www.atins.my.id/)
## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Sections

- Hero & About
- Skills
- Projects
- Certificates
- Education
- Experience
- Contact

## Getting Started

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm i
npm run dev
```

## Deployment

Open [Vercel](https://vercel.com/) → Import Project From Github → Publish → Custom domain.
